Politique de confidentialité (RGPD)

Dernière mise à jour : Janvier 2026

1. Responsable du traitement

SENSIUM-X — contact@sensads.com — Algérie.

2. Données collectées

  • Compte utilisateur : email, nom, mot de passe (hashé), rôle
  • Organisation : nom, NIF/NIS/RC, adresse, contact, configuration financière
  • Activité : devis, BDC, campagnes, KPIs, factures liés à votre organisation
  • Tokens OAuth Meta/Google (chiffrés via pgcrypto)
  • Logs d'audit : actions sensibles tracées immutablement (5 ans)

3. Finalités

Exécution des prestations de Digital Traffic Management, facturation, conformité légale.

4. Base légale

Exécution du contrat (CGV) et obligations légales (facturation, comptabilité).

5. Conservation

  • Données comptables (factures, BDC) : 10 ans (obligation légale)
  • Audit logs : 5 ans
  • Compte utilisateur : durée de la relation contractuelle + 2 ans
  • Médias campagnes : 90 jours puis archivés

6. Vos droits (RGPD)

  • Accès : export complet de vos données via l'app (Edge Function gdpr-export-user-data)
  • Rectification : depuis votre profil
  • Effacement : sur demande à contact@sensads.com (soft-delete 30j puis hard-delete sauf contraintes légales)
  • Portabilité : export JSON via l'app
  • Opposition : pour les communications marketing uniquement

7. Sécurité

  • RLS PostgreSQL sur toutes les tables
  • Tokens OAuth chiffrés via pgcrypto
  • 2FA TOTP obligatoire pour les administrateurs
  • Audit logs immutables
  • Backups quotidiens chiffrés (GPG) hors-site

8. Sous-traitants

  • Supabase (hébergement DB) — Frankfurt, Allemagne (UE)
  • Hostinger (hébergement web) — Lituanie (UE)
  • GitHub (code source + backups privés) — USA (clauses standard UE)

9. Loi 18-07 Algérie

Conformité avec la loi algérienne 18-07 du 10 juin 2018 relative à la protection des personnes physiques dans le traitement des données à caractère personnel.

10. Contact DPO

contact@sensads.com
